# Ajmal Garden Nursery Product Photo Library

This folder is the organised home for the real product photography supplied for the website.

## Important

The photos shared in the chat are not transferred into the website filesystem automatically. Save the original image files into the matching paths below. The Products page is already wired to these exact file names and will show the real photo as soon as it is present. Until then it uses a safe category-image fallback, so the site does not show broken images.
